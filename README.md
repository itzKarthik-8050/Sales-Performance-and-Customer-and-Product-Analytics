# Sales Performance and Customer Analytics

## Project Overview
Developed an interactive Power BI dashboard to analyze sales performance,
product categories, customer contributions, and regional sales.

## Dashboard Pages
1. Sales Overview
2. Product Performance

## Tools Used
- Power BI
- DAX
- Power Query
- Data Visualization

## Key Features
- Total Sales, Orders, and Customers KPIs
- Monthly Sales Trend
- Sales by Category and Sub-Category
- Top Products by Sales
- Customer and Regional Analysis

## Objective
To identify sales trends, evaluate product performance,
and support data-driven business decisions.
